Obscura

Un navigateur sans fenêtre.

Obscura charge les pages, exécute leur JavaScript et répond aux mêmes commandes que Chrome. Il est écrit en Rust et son code est ouvert.

Télécharger la dernière version

Ce qu'il sait faire

Parler comme Chrome

Il comprend le protocole Chrome DevTools (CDP). Vos scripts actuels peuvent le piloter.

Lire le JavaScript des pages

Les pages qui se construisent côté navigateur s'affichent complètes.

Suivre et filtrer le réseau

Observez les requêtes d'une page et intervenez dessus.

Garder les cookies

La session reste ouverte d'une visite à l'autre.

Limiter les signaux d'automatisation

Un mode furtif réduit ce qui trahit un navigateur piloté par un programme.

Ce que contient le dépôt

  • obscuraLe programme principal
  • obscura-browserLe navigateur
  • obscura-cdpLe protocole DevTools
  • obscura-cliLa ligne de commande
  • obscura-domLa structure de la page
  • obscura-jsLe JavaScript
  • obscura-mcpLe lien avec les assistants IA
  • obscura-netLe réseau

À quoi ça sert

  • Lire des sites pour la veille
  • Tester un site automatiquement
  • Suivre des prix et des produits
  • Auditer le référencement
